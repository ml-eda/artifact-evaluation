# AutoBench

Paper: "AutoBench: Automatic Testbench Generation and Evaluation Using LLMs for
HDL Design"

Links:

* [Paper DOI](https://doi.org/10.1145/3670474.3685956)
* [Artifact DOI](https://doi.org/10.5281/zenodo.13325723)
* [Artifact repository](https://github.com/AutoBench/AutoBench)

Useful aspects for MLCAD 2026 authors:

* Provides a historical MLCAD example of an LLM-based artifact.
* Shows artifact materials related to model/API use, generated outputs, metrics,
  and evaluation workflow.
* Helps authors understand why the MLCAD 2026 instructions ask for explicit
  model identity, prompts, inference settings, metrics, cached outputs, and
  tolerance or similar-result criteria.

MLCAD 2026 authors should provide the more detailed LLM information requested in
the current submission instructions, especially for API models, stochastic
outputs, cost, and local/runtime requirements.
