# MLCAD 2024 artifact examples

This folder collects selected MLCAD 2024 papers and public artifact materials
that can be used as examples when preparing MLCAD 2026 Artifact Appendices.
These are historical examples only. Authors should still follow the current
MLCAD 2026 requirements in the main submission and reviewing instructions,
including the Zenodo requirement, Functional evaluation criteria, and
LLM-specific fields when applicable.

The paper PDFs are not copied into this repository. Use the DOI links below to
access the official paper pages, and use the artifact DOI or repository links to
inspect the public artifacts.

| Paper | Why it is useful | Links |
| --- | --- | --- |
| [HLSFactory: A Framework Empowering High-Level Synthesis Datasets for Machine Learning and Beyond](hlsfactory.md) | Framework artifact with source code, AE scripts, Zenodo archives, datasets, and commercial-tool disclosure. | [Paper DOI](https://doi.org/10.1145/3670474.3685961), [Artifact DOI](https://doi.org/10.5281/zenodo.12989544), [Source repository](https://github.com/sharc-lab/HLSFactory), [Artifact evaluation repository](https://github.com/sharc-lab/hlsfactory-artifact-eval) |
| [AutoBench: Automatic Testbench Generation and Evaluation Using LLMs for HDL Design](autobench.md) | Historical LLM artifact example with model/API use, metrics, generated outputs, and tolerance discussion. | [Paper DOI](https://doi.org/10.1145/3670474.3685956), [Artifact DOI](https://doi.org/10.5281/zenodo.13325723), [Artifact repository](https://github.com/AutoBench/AutoBench) |
| [Efficient and Effective Neural Networks for Automatic Test Pattern Generation](nn-for-atpg.md) | Compact Functional evaluation example that maps scripts to paper results and states expected output/tolerance. | [Paper DOI](https://doi.org/10.1145/3670474.3685939), [Artifact repository](https://github.com/lzzh97/NN-for-ATPG), [Program archive](https://doi.org/10.5281/zenodo.13218515) |
