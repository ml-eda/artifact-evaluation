# HLSFactory

Paper: "HLSFactory: A Framework Empowering High-Level Synthesis Datasets for
Machine Learning and Beyond"

Links:

* [Paper DOI](https://doi.org/10.1145/3670474.3685961)
* [Artifact DOI](https://doi.org/10.5281/zenodo.12989544)
* [Source repository](https://github.com/sharc-lab/HLSFactory)
* [Artifact evaluation repository](https://github.com/sharc-lab/hlsfactory-artifact-eval)

Useful aspects for MLCAD 2026 authors:

* Separates the source repository from the artifact-evaluation workflow.
* Provides a public artifact archive through Zenodo.
* Shows how a framework-style artifact can describe datasets, scripts, and
  expected evaluation steps.
* Includes commercial-tool context that can help authors understand what needs
  to be disclosed when a workflow depends on external EDA tools.

MLCAD 2026 authors should still follow the current MLCAD 2026 submission
instructions for Zenodo archival, Functional evaluation criteria, and dependency
disclosure.
