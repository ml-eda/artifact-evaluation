# MLCAD Artifact Evaluation 
The artifact evaluation process has been adopted from the [MLCommons Community](https://github.com/mlcommons/ck/tree/master/docs/artifact-evaluation). It has been tailored for the MLCAD Conference.

The ACM artifact badging framework includes Artifacts Available, Artifacts Evaluated - Functional, and Results Reproduced. For MLCAD 2026, the artifact evaluation process will award only Artifacts Available and Artifacts Evaluated - Functional. MLCAD 2026 will not award a Results Reproduced / Reproducible badge.

Please refer to the [submission](submission.md), [checklist](checklist.md), and [reviewing](reviewing.md) documents in this repository for details on submitting your artifacts and the reviewing guidelines for MLCAD.
