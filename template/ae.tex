\subsubsection{Commercial software and PDK dependencies}

If applicable, list the exact tool, version, license assumptions, PDK or
technology package, required files, setup or mount paths, environment variables,
and smoke-test command. Do not include restricted installers, license files, or
PDK contents unless redistribution is allowed.

\subsubsection{Data sets}

Describe included, downloaded, generated, or proprietary data sets, including
versions, sizes, licenses or usage restrictions, and any public proxy data.

\subsubsection{Models}

For model-based artifacts, specify the exact model or API model, availability
or access instructions, version/revision where applicable, and license or usage
restrictions. For closed API models, include the provider, model ID, endpoint or
service version if available, experiment date range, access assumptions, and
known model-drift limitations. If LLMs materially affect the results, also
summarize the prompts, inference settings, metrics, raw or cached outputs,
tolerance bands, and expected API cost or local compute needed for validation.
